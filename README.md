# 💳 Bank Account Simulation (Java)

## 📌 Objective

This project simulates basic banking operations using Java and Object-Oriented Programming (OOP) concepts.

---

## 🛠️ Tools Used

* Java
* VS Code
* Terminal

---

## 🚀 Features

* Create a bank account
* Deposit money
* Withdraw money
* Check account balance
* View transaction history

---

## 🧠 Concepts Used

* Classes and Objects
* Encapsulation
* ArrayList (for storing transaction history)
* Menu-driven programming

---

## 📂 Project Structure

```
BankSimulation.java
```

---

## ▶️ How to Run

1. Open terminal in the project folder
2. Compile the program:

```
javac BankSimulation.java
```

3. Run the program:

```
java BankSimulation
```
